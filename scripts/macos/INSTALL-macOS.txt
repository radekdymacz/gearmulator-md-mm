{{PRODUCT_NAME_MD}} and {{PRODUCT_NAME_MM}} for macOS
================================================

Needs macOS 12 or later (Intel and Apple silicon).
This alpha is ad-hoc signed and is not notarized by Apple. macOS may quarantine
the applications, VST3 plug-ins, and Audio Units when you download them.

Installation
------------

1. Fully extract the downloaded ZIP archive.
2. Double-click macsetup_Gearmulator-Elektron.command in the extracted folder.
   Terminal will open, prepare both products, and print "Done" when successful.
3. Copy the VST3 plug-ins you want to use to:

       ~/Library/Audio/Plug-Ins/VST3

   Create that folder if it does not already exist.
4. Copy the Audio Units you want to use to:

       ~/Library/Audio/Plug-Ins/Components

   Create that folder if it does not already exist.
5. Optionally copy the standalone applications to /Applications or another
   location of your choice.
6. Restart your DAW or ask it to rescan plug-ins.

Run the setup command again whenever you install an updated download. The
command only clears extended attributes from the {{PRODUCT_NAME_MD}} and
{{PRODUCT_NAME_MM}} bundles in the extracted folder; it does not copy or delete
plug-ins.

Upgrading from 0.3.1 or earlier: the bundles were called {{LEGACY_NAME_MD}} and
{{LEGACY_NAME_MM}} then (and in the earlier preview builds). Copying the new
ones does not remove the old ones: a DAW then lists the editor twice, and an old
Audio Unit can take the new one's place (same plug-in codes; macOS keeps one),
so the AU opens the old panel instead of the editor. Delete the old-named .vst3
and .component (and .app) from every place they are in:

   /Library/Audio/Plug-Ins/VST3, /Library/Audio/Plug-Ins/Components, /Applications
   ~/Library/Audio/Plug-Ins/VST3, ~/Library/Audio/Plug-Ins/Components, ~/Applications

The installer packages (.pkg) delete these for you.

Firmware is not included. If no supported firmware image is found, the
application or plug-in shows a start-up card asking for it. Click the card and
choose a firmware image that you are entitled to use in the file chooser; the
editor checks it and copies it into its ROM folder. You can also copy the image
into that folder yourself and click Check again.

Do NOT discuss firmware or ROMs in Discord.
Do not request or share files or download links, or ask for help obtaining
or installing firmware.
