A screen-native editor for the {{MACHINE}}, running the machine's real firmware in an emulator. It installs three things, and you can leave any of them out under Customize:

  • {{APP_NAME}}.app into Applications
  • {{STEM}}.vst3 into Library/Audio/Plug-Ins/VST3
  • {{STEM}}.component (Audio Unit) into Library/Audio/Plug-Ins/Components

For all users, or for you only

At Destination Select (or Change Install Location…) you choose:

  • Install for all users of this computer: /Applications and /Library/Audio/Plug-Ins. This needs an administrator's password.
  • Install for me only: ~/Applications and ~/Library/Audio/Plug-Ins in your home folder. No administrator needed, so this works on a managed Mac or a standard account too.

Bring your own ROM

No firmware is included, and none can be provided. After installing, copy the complete firmware image (.bin, 8 MiB) from your own {{MACHINE}} into:

~/Documents/Gearmulator Preview/{{DATA_FOLDER}}/roms/

If no firmware is found, the editor says so and opens that folder for you. Put the file there, then restart the app or reload the plug-in.

Early release

This is an early release. Save your work often and keep backups of anything you care about. HW MIDI (driving a real {{MACHINE}}) is beta and has not been tested on real hardware yet.
