Machinedrum Editor + Monomachine Editor 0.3.0

Released 2026-10-05

A feature release on top of 0.2.1: a sampler workspace, a Sound page grouped by function, a keyboard for both editors, channel strips on the Monomachine's Mix, and a gentler first run when no ROM is installed yet.

Screenshots, features and FAQ: https://mdmm.dev Pay what you want (optional, same download): https://mdmm.dev/get/

What's new

Sampler (Machinedrum)

  • Sample slots are a browser of waveform tiles, with real waveforms drawn.
  • Load a WAV or AIFF file and audition it before you keep it.
  • The sampler's RAM view shows steps like the Sequence page; length is set in steps and bars.
  • Kit edits to the sampler survive a pattern dump from the machine.
  • "Set up sampling" is one centred card: recorder, then player.

Sound page by function

  • Both editors group the Sound page by what the controls do: small groups per machine, aligned rows, one screen per group. Pop-ups open in view.

Keyboard and playing

  • Mnemonic keys for the pages and actions, plus a QWERTY keyboard for playing notes.
  • Alt (Option) works the same on every page.
  • Kits load as soon as you click them. Song chains start playing at once, and the Song page is simpler.
  • Rhythm generators and sound mutation: roll a new pattern or vary a sound, then undo it.
  • A clickable transpose keyboard, a compact routing graph, a larger joystick and a short keyboard on the Monomachine's Perform page.
  • Drag across the M or S keys to mute or solo many tracks at once.

Monomachine

  • Mix: channel strips with a PAN bar, small AMP VOL, DIST and DSND boxes, and one labelled LEVEL fader.
  • Piano roll: the keys and octave labels sit on the left, with one left edge for every row.
  • Features of the Machinedrum Editor that the Monomachine was missing are now there too.
  • The Sequence page's lock lane lines up with the LOCK PARAMETER keys, on both editors.
  • The top bar fits a 1280 pixel wide window on both editors.

Starting without a ROM

  • A missing ROM is no longer an error: no pop-up alerts, just a start-up card asking for the ROM. You choose the file with the file chooser (drag and drop is not supported).
  • A session opened without a ROM keeps your saved project, and in a DAW it restores the automation and the editor setup from the held project.
  • LOAD ROM replaces or removes the firmware.
  • Questions in the editors read as sentences, and the LCD tooltip never covers an open menu.

Changed

  • MIDI mapping (the Control workspace and the LEARN key) is hidden until the controller feature exists. Each editor has five workspaces. Alt-drag on all tracks (Control All) is unchanged.

Release review fixes

  • Monomachine edits no longer wait forever. If the machine never opens GLOBAL > SYSEX RECV, the edit fails with a message after about half a minute of machine time, and PLAY, STOP and RECORD work again. In a DAW with audio stopped, nothing fails until the emulator runs again.
  • A pattern or kit that does not answer is asked for again. Over HW MIDI, a lost reply no longer leaves the editor refusing every edit; you get one message, and the editor asks again when the machine answers. The Monomachine's loading progress always finishes.
  • No more lost or repeated messages to the editor page: odd numbers, a comma-decimal system language, Polish letters and emoji no longer break the page, and dialogs no longer show twice when the window is shown again.
  • Each editor window gets its own notices, also with two windows open.
  • Solo keeps your mutes on the Machinedrum: un-solo no longer unmutes tracks muted on the machine or in the project, and a sampler capture stays frozen.
  • No shortcuts behind dialogs: Space presses the dialog's button, and Delete or the number keys no longer act on the page behind it. Undo still works over the library and GLOBAL panels.
  • Dialogs wait their turn, so a question from the plug-in is never lost behind another one.
  • HW MIDI says when no machine answers: the editor dims and a card offers AUDIO / MIDI or the emulator. The Monomachine's unsent edits (SEND n) no longer look like SYNC.
  • Errors show once, under the header, without moving the page, and close with ×.
  • GLOBAL › ROUTING fits its dialog; the Monomachine's Multi map is never covered by the joystick, and Perform scrolls in a short window; Monomachine texts no longer name the Machinedrum.
  • Safer data handling: bad song or pattern data can no longer write outside its memory.

Found by the new user-journey tests

  • Machinedrum GEN offers each track's own generator from the start; before, every track said Keep until you pressed Defaults.
  • Arrow keys on a Sound value keep stepping that value on both editors; before, the second ↑ selected another track.
  • Monomachine RECORD right after an edit now records. A key pressed while the machine was still taking a dump was lost; the editor now says the panel is busy for that moment.
  • A drag over many steps keeps every step on the Monomachine (it lost the later ones), and a rotate's undo step no longer swallows the edits after it, on both editors.

Also new on the Monomachine

  • Black keys: W E T Y U O P play the semitones on the QWERTY keyboard. Tap tempo is B (on the Machinedrum, B and T both tap).
  • Paint in the piano roll: press an empty cell and drag to paint that note across the empty steps; Alt-drag erases. One drag is one undo step.

Known

  • Unsigned and not notarised: on macOS 15 and later, double-click the installer, then open System Settings > Privacy & Security, scroll down and click Open Anyway. Right-click > Open no longer works for installers.
  • macOS only for now, tested on Apple silicon.
  • A kit that contains a CTR-AL machine cannot be edited in the Machinedrum Editor yet.
  • Bring your own ROM. No firmware is included.
