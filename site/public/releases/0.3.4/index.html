Machinedrum Editor + Monomachine Editor 0.3.4

Released 2026-10-08

A fix release on top of 0.3.3, with a new keyboard map for the Machinedrum Editor.

Screenshots, features and FAQ: https://mdmm.dev · User guide: https://mdmm.dev/guide/

Fixes

  • No more drop-outs while editing in a DAW (both editors). Every edit used to reach the machine at once: a parameter-lock drag sent the whole pattern up to five times a second, and each one kept the emulation busy on the audio thread, so a slower Mac missed audio buffers. While the machine plays, everything the editor sends now goes in one queue at the speed of a real MIDI cable, and the newest value wins while it waits. In a six-second lock drag the machine now takes 5 patterns instead of 31, and the audio thread runs hot about a sixth as long as before. The first edit is heard at once; during a long drag the machine follows at most about two seconds behind.
  • Big imports run at full speed while the machine is stopped; while it plays they go at MIDI-cable speed so the audio never drops out. A full Machinedrum backup's 128 patterns take about 14 seconds while stopped, and about four minutes while playing.
  • SysEx imports finish cleanly. A big import used to end with a flood of "Push failed" messages and old patterns on screen, although the machine had taken them in. The editor now checks the documents a couple at a time.
  • ⌘C, ⌘V and ⌘X work in DAWs and in the app (Ctrl+C, Ctrl+V, Ctrl+X on Windows and Linux). Before, the plug-in window swallowed them on macOS.
  • Lighter page graphics while playing (Machinedrum Editor): the moving play head no longer redraws a column of steps at every step, so the editor's window costs far less while the pattern plays.

New

  • The version is shown: next to Setup in the top bar, in the keyboard view, as the first line of the right-click menu (with the Updates entries under it), and in the app's About box (the app menu on macOS, Help on Windows and Linux).

New: the keyboard map (Machinedrum Editor)

  • ⌘-click and ⌘-drag select steps (Ctrl on Windows and Linux); ⌘⇧-click extends the selection.
  • Right-click a step for the step menu: trig, accent, slide, copy, paste, duplicate, clear, and the fill (every 2nd or 4th step) that used to be on ⌘-click.
  • FN button in the top bar: the next click, drag or key acts on every track, like holding ⌥ (double-click keeps it on).
  • ? shows a keyboard view with every key and what it does.
  • Delete with nothing selected no longer clears the page; it tells you how (Clr, or ⌥Delete for the whole pattern).
  • COPY, CLR and PASTE in the LCD act on the selected steps when steps are selected.
  • The Monomachine Editor gets the same selection and step menu next.

Platforms

  • macOS 12 or later (Intel and Apple silicon), not signed by Apple yet: the first install needs Open Anyway.
  • Windows x64 and Linux x64: not tested by a person yet. Feedback welcome: https://mdmm.dev/contact/
