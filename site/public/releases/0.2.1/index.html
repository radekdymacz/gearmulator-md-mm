Machinedrum Editor + Monomachine Editor 0.2.1

A fix and speed release on top of 0.2.0. The editors no longer crash when you quit, the Monomachine's Sound tab always opens, and fast editing no longer loads the emulator so much that audio glitches in a DAW.

Screenshots, features and FAQ: https://mdmm.dev Pay what you want (optional, same download): https://mdmm.dev/get/

What's new

Control All

  • Alt-drag (Option-drag) a value to move that knob on every track, like the Machinedrum's FUNCTION + DATA ENTRY knob (manual p.37). It now works on every page, the Sound page's LFO boxes and curve editors too. One drag is one undo step.
  • On the Machinedrum emulator the editor uses the machine's own FUNCTION + knob gesture, so the machine decides which tracks move (MIDI and CTRL machines stay; RAM recorders stay on their synthesis page), exactly as on the hardware.
  • New on the Monomachine's Sound workspace: the same Alt-drag moves the knob on all six synth tracks. MIDI tracks are left alone.

Smoother while you edit

  • Drawing parameter locks sends the pattern to the machine at most five times a second (latest value wins) and reads it back once when you stop. The screen still follows at once. In a VST3 host this cut the Machinedrum's extra emulator load while drawing from about +20 % to under +5 %.

Fixed

  • Quitting crashed both editors (the standalone apps and the plug-ins' teardown): the editor window now closes before the machine session.
  • The Monomachine's Sound tab could open empty: the page sometimes started before its value tables had loaded, and tracks with an LFO on another page failed to draw.
  • Both installers keep "Install for me only".

Known

  • Unsigned: macOS asks you to allow the app the first time (System Settings > Privacy & Security).
  • A kit that contains a CTR-AL machine cannot be edited in the Machinedrum Editor yet.
  • Bring your own ROM. No firmware is included.
