Release notes

Machinedrum Editor + Monomachine Editor 0.2.0

The second release of the screen-native editors for the Elektron Machinedrum and Monomachine, running each machine's real firmware. This one is about polish: a layout that scales, a calmer start, installing the ROM from the editor, SysEx backups, and plug-ins that follow the DAW. The Monomachine Editor now drives every machine feature it used to grey out, and both installers can install for you only, without an administrator password.

Screenshots, features and FAQ: https://mdmm.dev Pay what you want (optional, same download): https://mdmm.dev/get/

What's new

A layout that scales

  • The page uses the whole window. Rows are fluid, the lock lane never overflows, and the Sound and engine pages use the space they have.
  • The window fits the screen: it opens inside the visible area (above the Dock) and remembers its size. The editors resize freely.
  • Workspace keys are bigger and even; the lane legend and paging sit in the same places in both apps. The Monomachine's Mix strips put each fader and its level in one column.
  • One LCD for both apps, on a real pixel grid. Its sync slot shows SYNC, SEND, RECV, HOST, or the background read's progress ("170/288").

Editing

  • All steps are shown by default. PAGE, the page LEDs and FOL still page if you prefer.
  • Drag-paint: drag across steps to paint trigs (Machinedrum) or SLIDE, SWING and envelope steps (Monomachine). One drag is one undo step.
  • Shift-armed mutes: hold Shift, pick the tracks to mute or unmute, release to send them all at once, on both machines.
  • Monomachine LEN can be changed again: a click steps 16, 32, 48, 64 and round, Shift-click steps back, and the scroll wheel steps by one.
  • Fixed: a freshly loaded pattern was flagged "edited" and asked to save on every load. A drag that outlived a redraw kept editing on plain mouse moves; gestures now always end.

Monomachine: the machine's own features

Everything the Monomachine Editor showed as "not yet" works now:

  • MIDI track mutes and solos (the machine's MUTE window). The rail, Mix and Perform also show the mutes you make on the machine's own panel.
  • POLY: the Perform keyboard's POLY key switches the machine's audio mode, and follows it.
  • MULTI TRIG: mode (ALL TRK, SPLIT KEY, SEQ START, SEQ TRNSP), the split key and track, and the timing (DIRECT to 32/16).
  • MULTI MAP: every range's pattern, offset, length, transpose and timing; split and delete ranges.
  • PORTAMENTO mode per track: ALWAYS or ONLY LEGATO.
  • RECORD: stopped, the record key is GRID RECORDING; playing, LIVE RECORDING (the notes you play are recorded). What the machine records shows in the editor while it records.
  • Any of the 24 songs: a song picker in the Song workspace, and Load on the machine (LOAD SONG).
  • Undo reaches library slot writes too (a kit or pattern copied, cleared or renamed).
  • Some kit bytes the earlier versions had guessed are now read from the machine itself (the JOY mirror, key tracking HPF and LPF), and a changed global takes effect at once.

HW MIDI for the Monomachine

  • The Monomachine takes pattern, song, global and stored-kit dumps only on its SYSEX RECV screen, which the editor cannot open over MIDI. The edits wait, and the pattern field shows SEND n. Click it: the dialog says how to open GLOBAL › FILE › SYSEX RECV on the machine, and Send now sends them. Kit sounds (CCs) go out at once as before.
  • PLAY and STOP are MIDI Start and Stop. A factory Monomachine ignores them (CONTROL IN TRANSPORT IGNORE); PLAY then offers to set TRANSPORT to ACCEPT in the active global.
  • The MIDI track mutes and RECORD have no MIDI message on the machine, so over HW MIDI they are disabled, and say why.

Dialogs and start-up

  • Centred modals with a backdrop, one system in both apps: questions start on Cancel and Esc answers Cancel; panels close on Esc or a click outside.
  • The start-up screen shows the machine's real firmware LCD, mirrored big, with a progress bar. It fades as soon as the machine takes input.

ROM install and hot reload

  • No ROM yet, or the wrong one? Drag the firmware file onto the window, or click Choose ROM file…. The editor checks it (8 MiB, the right machine and OS), copies it into the ROM folder without overwriting anything, and restarts the machine straight away. No restart of the app or plug-in needed. Nothing leaves your computer. A .zip holding the image works too.

SysEx import and export

  • Import SysEx… (in both libraries), or drop a .syx on the window. A preview lists what the file holds, what it will overwrite, and what this OS cannot take. The kinds you choose go in as one undo step, with progress and Stop. Globals are off by default.
  • Export SysEx… writes everything the editor holds to one .syx: a full backup.
  • Limits with backups made by older OS versions:
    • Machinedrum: globals from an older OS are converted by OS 1.63; kit names with bytes outside the name format read back with a different name.
    • Monomachine: OS 1.32B ignores kit dumps from older OS versions (they are shorter), so the preview leaves them out. Patterns with a note but no trig do not validate and are left out.

In your DAW

  • Both plug-ins follow the DAW's tempo and transport. The LCD's sync slot shows HOST.
  • In a DAW, HW MIDI is off (the plug-in has no MIDI output to the machine); use the standalone app for HW MIDI.

Under the hood

  • A simpler core shared by both editors: documents, undo and pending writes are owned by the plug-in, so they survive closing the window. A command that would lose two things now asks one question that names both.

Install (macOS)

FileInstalls
Machinedrum-Editor-macOS.pkgMachinedrum Editor.app, Gearmulator MD.vst3, Gearmulator MD.component
Monomachine-Editor-macOS.pkgMonomachine Editor.app, Gearmulator MM.vst3, Gearmulator MM.component

Where they go is your choice in the installer (Destination Select, or Change Install Location…):

ChoiceAppPlug-insPassword
Install for all users of this computer/Applications/Library/Audio/Plug-Ins/VST3, /Library/Audio/Plug-Ins/Componentsan administrator's
Install for me only~/Applications~/Library/Audio/Plug-Ins/VST3, ~/Library/Audio/Plug-Ins/Componentsnone: works on a standard or managed account
  1. Download the package for your machine.
  2. The packages are not signed yet (there is no Apple Developer ID for the project), so macOS blocks them on a plain double-click. Open one in any of these ways:
    • Right-click (or Control-click) the .pkg in Finder, choose Open, then Open again.
    • Or double-click it, dismiss the warning, then go to System Settings › Privacy & Security, scroll down and click Open Anyway next to the package's name.
    • Or in Terminal: xattr -d com.apple.quarantine ~/Downloads/Machinedrum-Editor-macOS.pkg
  3. Follow the installer. At Destination Select pick Install for all users (it asks for an administrator's password, because it writes to /Applications and /Library) or Install for me only (no password; your home folder). Customize lets you leave out the app, the VST3 or the AU.
  4. If the app is blocked the first time you open it, do the same: right-click it in Applications and choose Open, or use Open Anyway, or run: 
   xattr -dr com.apple.quarantine "/Applications/Machinedrum Editor.app"
   xattr -dr com.apple.quarantine "/Applications/Monomachine Editor.app"

(installed for you only: "$HOME/Applications/Machinedrum Editor.app" and so on)

  1. Rescan plug-ins in your DAW. The plug-ins are listed as Gearmulator MD and Gearmulator MM (instruments). Installing over 0.1.0 alpha in the same place replaces it. Keep one copy only: with one in /Library/Audio/Plug-Ins and another in ~/Library/Audio/Plug-Ins (installed for you only, or an earlier build copied by hand) the DAW lists two, so delete the one you do not want.

Terminal install, for scripts:

# for all users
sudo installer -pkg Machinedrum-Editor-macOS.pkg -target /
sudo installer -pkg Monomachine-Editor-macOS.pkg -target /
# for you only, no sudo
installer -pkg Machinedrum-Editor-macOS.pkg -target CurrentUserHomeDirectory
installer -pkg Monomachine-Editor-macOS.pkg -target CurrentUserHomeDirectory

To remove: delete the three bundles from where you installed them (the tables above). Your firmware and settings in ~/Documents stay.

Bring your own ROM

No firmware is included, and none will be provided. The Elektron firmware is Elektron's copyright; the editors are for people who own the machine.

The easiest way: start the editor, then drag your machine's complete 8 MiB firmware image (.bin, or a .zip holding it) onto the window, or click Choose ROM file…. It is copied to:

MachineFolder
Machinedrum~/Documents/Gearmulator Preview/Machinedrum/roms/
Monomachine~/Documents/Gearmulator Preview/Monomachine/roms/

You can also copy the file there yourself. Tested firmware: Machinedrum UW OS 1.63 and Monomachine SFX-60 OS 1.32B.

Please do not ask for, share or link firmware files in the issues or on Discord.

Known limits

  • Unsigned. There is no Apple Developer ID yet, so the packages and apps are not signed or notarized; use the Gatekeeper steps above (right-click › Open, Open Anyway, or xattr).
  • HW MIDI is still beta and untested on real hardware. It is verified against the emulator acting as the MIDI peer. Reports from real machines are very welcome.
  • Standalone sync: Ableton Link is coming in v0.3. Until then the standalone runs on its own clock; MIDI clock over the IAC bus works through the machines' own global sync settings, but it is not in the editor's UI yet.
  • DAW sync was checked with the firmware test rig; please report anything odd in your DAW (tempo changes, loops, stop).
  • Machinedrum: LOCAL CTRL and TRIG IN A/B are stored and shown, but their effect is not verified.
  • Monomachine: STEP RECORDING (STOP + RECORD) is not on the page; the record key uses GRID and LIVE.
  • Over HW MIDI some controls are disabled because the machine has no MIDI message for them (the editor says why): on the Monomachine the MIDI track mutes and RECORD. Over HW MIDI the Monomachine cannot report its mutes, playhead or tempo, and edits made on the machine before connecting are seen only after SAVE KIT.
  • Names inside the apps still read "Gearmulator MD" / "Gearmulator MM", and the data folder is ~/Documents/Gearmulator Preview.
  • macOS only. Tested on macOS 27 on Apple silicon; the Intel slice is built and checked but not played on an Intel Mac.
