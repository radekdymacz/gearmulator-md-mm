Download

Your download has started. If the editor earns a place in your setup, you can name your price any time.

The installer puts the app in Applications and the VST3 and AU plug-ins in /Library/Audio/Plug-Ins. No administrator password? Choose Install for me only: then they go to ~/Applications and ~/Library/Audio/Plug-Ins in your home folder.

Prefer to place the files yourself? .dmg, loose files: the same app, VST3 and AU in a disk image, with no installer in it.

1 · Install
  1. Double-click the .pkg. It is not notarised by Apple, so macOS 15 and later blocks it. Open System Settings → Privacy & Security, scroll down to the message about the installer, click Open Anyway and confirm with your password or Touch ID. (Right-click → Open no longer works for installers there. On macOS 12 to 14 it does: right-click the .pkg and choose Open.)
  2. At Destination Select (or Change Install Location…) pick Install for all users (needs an administrator) or Install for me only (works on a standard or managed account).
  3. Rescan plug-ins in your DAW. Upgrading from 0.3.1 or earlier: the installer removes the old Gearmulator MD and Gearmulator MM plug-ins. If your DAW still lists the editor twice, delete the old-named .vst3 and .component by hand from /Library/Audio/Plug-Ins and ~/Library/Audio/Plug-Ins.
2 · Add your ROM
  1. Use your own firmware image: Machinedrum OS 1.63 or Monomachine OS 1.32B, 8 MiB. It is not included.
  2. Open the editor. With no ROM it shows a start-up card, Machinedrum firmware needed (or Monomachine). Click the large area, Choose your Machinedrum OS 1.63 ROM (.bin or .zip, 8 MB), and pick the file in the file chooser. On macOS you can also drop the file onto the window; on Windows and Linux use the file chooser.
  3. The editor checks the file and copies it into its ROM folder, ~/Documents/Gearmulator Preview/<machine>/roms/. You can also put the image there yourself and click the Check again link. It then starts the machine, which takes 10–15 seconds.
  4. Details and keys: the user guide.

1 · Install
  1. Unzip the file. It holds the app (Machinedrum Editor.exe or Monomachine Editor.exe), the plug-in (the .vst3 folder) and a README.
  2. Run the app from the unzipped folder. If Windows SmartScreen warns you, choose More info → Run anyway (the build is not signed).
  3. For your DAW, copy the .vst3 folders to C:\Program Files\Common Files\VST3 and rescan plug-ins.
  4. Needs Windows 10 or 11 with the Microsoft Edge WebView2 Runtime (current Windows has it; if it is missing, the editor window says so and links to Microsoft's download).

1 · Install
  1. Unpack the .tar.gz. Run the app in Standalone/ from where it is; keep the two .so files beside it.
  2. For your DAW, copy the whole .vst3 folder from VST3/ into ~/.vst3/ and rescan plug-ins.
  3. The editor window needs WebKitGTK: on Ubuntu or Debian sudo apt install libwebkit2gtk-4.1-0, on Fedora sudo dnf install webkit2gtk4.1, on Arch sudo pacman -S webkit2gtk-4.1. Needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12 or later). The README in the archive lists every package.
