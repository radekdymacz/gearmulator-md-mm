# Machinedrum Editor + Monomachine Editor 0.3.0

A feature release on top of [0.2.1](v0.2.1.md): a sampler workspace, a Sound page grouped by
function, a keyboard for both editors, channel strips on the Monomachine's Mix, and a gentler
first run when no ROM is installed yet.

Screenshots, features and FAQ: **https://mdmm.nativekloud.com**
Pay what you want (optional, same download): **https://mdmm.nativekloud.com/get/**

## What's new

### Sampler (Machinedrum)
- Sample slots are a browser of waveform tiles, with real waveforms drawn.
- Load a WAV or AIFF file and audition it before you keep it.
- The sampler's RAM view shows steps like the Sequence page; length is set in steps and bars.
- Kit edits to the sampler survive a pattern dump from the machine.
- "Set up sampling" is one centred card: recorder, then player.

### Sound page by function
- Both editors group the Sound page by what the controls do: small groups per machine, aligned
  rows, one screen per group. Pop-ups open in view.

### Keyboard and playing
- Mnemonic keys for the pages and actions, plus a QWERTY keyboard for playing notes.
- Alt (Option) works the same on every page.
- Kits load as soon as you click them. Song chains start playing at once, and the Song page is
  simpler.
- Rhythm generators and sound mutation: roll a new pattern or vary a sound, then undo it.
- A clickable transpose keyboard, a compact routing graph, a larger joystick and a short keyboard
  on the Monomachine's Perform page.
- Drag across the M or S keys to mute or solo many tracks at once.

### Monomachine
- **Mix:** channel strips with a PAN bar, small AMP VOL, DIST and DSND boxes, and one labelled
  LEVEL fader.
- **Piano roll:** the keys and octave labels sit on the left, with one left edge for every row.
- Features of the Machinedrum Editor that the Monomachine was missing are now there too.
- The Sequence page's lock lane lines up with the LOCK PARAMETER keys, on both editors.
- The top bar fits a 1280 pixel wide window on both editors.

### Starting without a ROM
- A missing ROM is no longer an error: no pop-up alerts, just a start-up card asking for the
  ROM. You choose the file with the file chooser (drag and drop is not supported).
- A session opened without a ROM keeps your saved project, and in a DAW it restores the
  automation and the editor setup from the held project.
- LOAD ROM replaces or removes the firmware.
- Questions in the editors read as sentences, and the LCD tooltip never covers an open menu.

### Changed
- MIDI mapping (the Control workspace and the LEARN key) is hidden until the controller feature
  exists. Each editor has five workspaces. Alt-drag on all tracks (Control All) is unchanged.

## Known
- Unsigned and not notarised: on macOS 15 and later, double-click the installer, then open
  System Settings > Privacy & Security, scroll down and click **Open Anyway**. Right-click > Open
  no longer works for installers.
- macOS only for now, tested on Apple silicon.
- A kit that contains a CTR-AL machine cannot be edited in the Machinedrum Editor yet.
- Bring your own ROM. No firmware is included.
