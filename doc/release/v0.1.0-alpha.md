# Machinedrum Editor + Monomachine Editor 0.1.0 alpha

The first public release of two screen-native editors for the Elektron Machinedrum and
Monomachine. Each one runs the machine's real firmware in an emulator and puts the whole machine
on one page: step grid, parameter-lock lanes, kit and pattern library, song chains, mutes, app
LFOs, and a HW MIDI mode that drives a real machine instead of the emulator.

- **Machinedrum Editor**: a step grid, lock lanes by page and
  index, kit/pattern library, chains, GLOBAL settings, a `?` key list, and LFOs that keep running
  with the editor closed.
- **Monomachine Editor**: a piano-roll sequencer, lock
  lanes, POLY, song picker, live and grid recording, and undo that covers library writes.

Both come as a standalone app, a VST3 and an Audio Unit for macOS (Apple silicon and Intel).

## Install (macOS)

| File | Installs |
|---|---|
| `Machinedrum-Editor-macOS.pkg` | `/Applications/Machinedrum Editor.app`, `/Library/Audio/Plug-Ins/VST3/Gearmulator MD.vst3`, `/Library/Audio/Plug-Ins/Components/Gearmulator MD.component` |
| `Monomachine-Editor-macOS.pkg` | `/Applications/Monomachine Editor.app`, `/Library/Audio/Plug-Ins/VST3/Gearmulator MM.vst3`, `/Library/Audio/Plug-Ins/Components/Gearmulator MM.component` |

1. Download the package for your machine.
2. The packages are **not signed yet** (there is no Apple Developer ID for the project), so macOS
   blocks them on a plain double-click. Open one in any of these ways:
   - **Right-click** (or Control-click) the `.pkg` in Finder, choose **Open**, then **Open** again.
   - Or double-click it, dismiss the warning, then go to **System Settings › Privacy & Security**,
     scroll down and click **Open Anyway** next to the package's name.
   - Or in Terminal: `xattr -d com.apple.quarantine ~/Downloads/Machinedrum-Editor-macOS.pkg`
3. Follow the installer. **Customize** lets you leave out the app, the VST3 or the AU. It asks for
   your password because it writes to `/Applications` and `/Library`.
4. If the app is blocked the first time you open it, do the same: right-click it in Applications and
   choose **Open**, or use **Open Anyway**, or run:

   ```sh
   xattr -dr com.apple.quarantine "/Applications/Machinedrum Editor.app"
   xattr -dr com.apple.quarantine "/Applications/Monomachine Editor.app"
   ```

5. Rescan plug-ins in your DAW. The plug-ins are listed as **Gearmulator MD** and **Gearmulator MM**
   (instruments). If you installed an earlier build by hand into `~/Library/Audio/Plug-Ins`, delete
   those copies so the DAW does not list two.

Terminal install, for scripts:

```sh
sudo installer -pkg Machinedrum-Editor-macOS.pkg -target /
sudo installer -pkg Monomachine-Editor-macOS.pkg -target /
```

To remove: delete the three bundles listed above. Your firmware and settings in `~/Documents` stay.

## Bring your own ROM

**No firmware is included, and none will be provided.** The Elektron firmware is Elektron's
copyright; the editors are for people who own the machine.

Copy the complete 8 MiB firmware image (`.bin`) from your own machine into:

| Machine | Folder |
|---|---|
| Machinedrum | `~/Documents/Gearmulator Preview/Machinedrum/roms/` |
| Monomachine | `~/Documents/Gearmulator Preview/Monomachine/roms/` |

If no firmware is found, the editor says so and opens the folder for you. Then restart the app or
reload the plug-in. Tested firmware: Machinedrum UW OS 1.63 and Monomachine SFX-60 OS 1.32B.

Please do not ask for, share or link firmware files in the issues or on Discord.

## Known limits

This is an alpha. Save often and keep backups.

- **HW MIDI is beta and untested on real hardware.** It was verified only against the emulator
  acting as the MIDI peer; no real Machinedrum or Monomachine has been connected yet. Reports are
  very welcome.
- Over HW MIDI, some controls are disabled because the machine has no MIDI message for them (the
  editor says why), edits made on the machine before connecting are not seen until SAVE KIT, and
  the Monomachine's MIDI track mutes shown are the editor's own.
- Machinedrum: LOCAL CTRL and TRIG IN A/B are stored and shown, but their effect is not verified.
  In the MAP EDITOR, START and QUE were not told apart, and CTRL keymap values (32 and up), if any,
  are not shown.
- Monomachine: STEP RECORDING (STOP + RECORD) is not on the page; the record key uses GRID and LIVE.
- The page is the only UI. The older hardware-panel skins are not part of these builds.
- Names inside the apps still read "Gearmulator MD" / "Gearmulator MM" (menu bar, DAW plug-in list)
  and the data folder is `~/Documents/Gearmulator Preview`.
- The standalone apps use stereo output. Extra output pairs are available in a multi-output VST3
  host.
- macOS only for now. Tested on macOS 27 on Apple silicon; the Intel slice is built and checked but
  not played on an Intel Mac. The packages are unsigned and not notarized.
