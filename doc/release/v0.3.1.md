# Machinedrum Editor + Monomachine Editor 0.3.1

A fix release on top of [0.3.0](v0.3.0.md).

Screenshots, features and FAQ: **https://mdmm.nativekloud.com**

## Fixes (Machinedrum)
- Unsaved kit edits are no longer lost when you click a step elsewhere.
- Kit values always reach the machine: undo after Control All is heard, and a value set right after a machine change stays.
- "Set up sampling" sets the recorder's volume to 0, so the recorder never records itself (no feedback loop).

## macOS
- Each machine also comes as a drag-and-drop disk image (.dmg), next to the installer (.pkg).
- The editors have their own bundle identifiers and settings files, apart from upstream Gearmulator. Settings from 0.3.0 and earlier are copied over on first start.
- The release pipeline is ready for Developer ID signing and notarization.

## Install
Bring your own ROM: nothing is bundled. If macOS says the app cannot be opened, go to
System Settings › Privacy & Security and click **Open Anyway**.
