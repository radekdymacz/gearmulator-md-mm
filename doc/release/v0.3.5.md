# Machinedrum Editor + Monomachine Editor 0.3.5

A fix release on top of [0.3.4](https://github.com/radekdymacz/gearmulator-md-mm/blob/main/doc/release/v0.3.4.md).

Screenshots, features and FAQ: **https://mdmm.dev** · User guide: **https://mdmm.dev/guide/**

## SysEx import
- **The file goes to the machine as it is, and the machine decides.** The editor no longer guesses which OS a dump is from. Old backups, public ones among them, now import in full: kits, patterns, songs and globals from earlier OS versions that used to be refused as "wrong OS".
- **The preview tells you what will happen**: what each item overwrites, what plays now, and that an import has no Undo (Export SysEx first). Untick a whole kind or click single items away.
- **A report per item** once the machine has read everything back: taken, converted by the machine, ignored, or different from the file.

## Fixes
- **Set up sampling no longer loses tracks 13 and 14** (Machinedrum Editor). In 0.3.4, chopping right after Set up sampling with the machine stopped put the tracks back to the kit's stored machines, together with every unsaved kit edit.
- **The arpeggiator range goes up to 9 octaves** (Monomachine Editor), as on the machine, and shows the right number: it used to read one octave too many.
- **Full screen and maximise work in the app**, and the app menu no longer has a Settings entry that did nothing.
- **? works without clicking into the window first** (both editors); in the Monomachine Editor it now opens the keyboard view.
- **Shortcuts work while a value is focused**, so ⌘Z (Ctrl+Z) undoes a Control All drag at once.
- **Perform no longer jumps while you drag** the envelope (Monomachine Editor).
- **Windows: a faster, more reliable start.** The editors try WebView2 again when it fails to start, write a start-up log, and say on screen what went wrong. **Open Log Folder** in the right-click menu finds the log to send us.

## New
- **The GLOBAL panel's note map names every target** (Machinedrum Editor): tracks, patterns A01 to H16, START and STOP. **Map a note** sends any note to any pattern, START or STOP. Maps from older backups now show as they are instead of being cut short.

## Platforms
- macOS 12 or later (Intel and Apple silicon), not signed by Apple yet: the first install needs **Open Anyway**.
- Windows x64 and Linux x64: not tested by a person yet. Feedback welcome: https://mdmm.dev/contact/
