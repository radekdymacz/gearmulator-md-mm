# Machinedrum Editor + Monomachine Editor 0.3.5

A fix release on top of [0.3.4](https://github.com/radekdymacz/mdmm/blob/main/doc/release/v0.3.4.md).

Screenshots, features and FAQ: **https://mdmm.dev** · User guide: **https://mdmm.dev/guide/**

## SysEx import
- **The file goes to the machine as it is, and the machine decides.** The editor no longer guesses which OS a dump is from. Old backups, public ones among them, now import in full: kits, patterns, songs and globals from earlier OS versions that used to be refused as "wrong OS".
- **The preview tells you what will happen**: what each item overwrites, what plays now, and that an import has no Undo (Export SysEx first). Untick a whole kind or click single items away.
- **A report per item** once the machine has read everything back: taken, converted by the machine, ignored, or different from the file.
- **A new import window** (both editors): one tab per kind (kits, patterns, songs, globals) with the machine's own slot grid, so you see which slots get overwritten and what plays now. Click a slot to leave it out (Shift-click for a range), or use All, Empty slots only and None. While it runs, each tab shows its own progress; the report marks every slot and can show the problems only.
- **Globals are off unless you tick them**: they change the machine's MIDI channels and settings. An imported global for the slot the machine uses is made active at once, so the machine and the editor agree on the MIDI channel, and the report says what each global changed. If a global sets the MIDI base channel to OFF, the editor says so instead of showing mutes the machine never took; GLOBAL sets a channel again.

## Fixes
- **Start-up diagnostics in the plug-in too** (both editors, B-035). While the machine starts, the start-up card says when the DAW is not running audio for the plug-in, or when the machine runs slower than real time; the start-up log (**Open Log Folder**) gets a line a second for the first 30 s, in the app and in a DAW.
- **The Monomachine Editor's play head costs less** (B-036): it moves without repainting the step cells and the piano rolls at every step, and the editor asks the emulator less often while the machine starts, as the Machinedrum Editor does.
- **TEMPO shows the DAW's tempo in a DAW** (both editors, B-030). The machine already followed the host's clock, but the LCD showed its own stored tempo. Now it shows the host's BPM (also while the DAW is stopped), marked DAW, and refuses edits: change the tempo in the DAW. The app is unchanged.
- **No more glitch when you save a project or close the app** (Machinedrum Editor): saving no longer holds up the audio for 25 to 30 ms. The app now fades out before it closes, so closing while a pattern plays no longer clicks.
- **Set up sampling no longer loses tracks 13 and 14** (Machinedrum Editor). In 0.3.4, chopping right after Set up sampling with the machine stopped put the tracks back to the kit's stored machines, together with every unsaved kit edit.
- **The arpeggiator range goes up to 9 octaves** (Monomachine Editor), as on the machine, and shows the right number: it used to read one octave too many.
- **Full screen and maximise work in the app**, and the app menu no longer has a Settings entry that did nothing.
- **? works without clicking into the window first** (both editors); in the Monomachine Editor it now opens the keyboard view.
- **Shortcuts work while a value is focused**, so ⌘Z (Ctrl+Z) undoes a Control All drag at once.
- **Perform no longer jumps while you drag** the envelope (Monomachine Editor).
- **A SysEx file chosen as the ROM** now says it is SysEx, not the ROM image, and where to import it.
- **Windows: a faster, more reliable start.** The editors try WebView2 again when it fails to start, write a start-up log, and say on screen what went wrong. **Open Log Folder** in the right-click menu finds the log to send us.

## New
- **The Song page shows what plays** (both editors). Its left column now goes from the top: **What plays** (a big PATTERN | SONG switch and one live line: PATTERN B07, SONG 01 · row 017 of 65 · B01, or CHAIN A03»A05), the song, the pattern palette, the selected row. While a song plays, the arrangement is framed as playing; in PATTERN mode it stays as it is, ready to edit, and the header says the song is not playing. The switch lights what the machine reports.
- **A song playhead** (both editors): while the machine plays a song, the row it plays is marked in the arrangement, read from the machine itself, so it follows repeats, loops and jumps; the time bar above the grid fills up to it, and the LCD's pattern slot reads SONG 01 · 017.
- **PAT / SONG on the LCD's second line**, on every page: click it to switch between pattern and song mode. The LCD keeps its size in both modes.
- **Song edits just play** (both editors): no more "Reload song". An edit made while stopped is heard at the next PLAY; one made while the song plays, from the next start; one made in pattern mode, when you switch to SONG.
- **GLOBAL key in the top bar** (Machinedrum Editor), where FN was: the machine's MIDI channel, sync, note map and routing. The AUDIO / MIDI panel points to it. FN is gone: ⌥, ⇧ and ⌘ remain, and the step menu keeps every ⌥ action.
- **The editor menu in the editors' own style** (both editors): right-click anywhere the page has no menu of its own. **Zoom** (the page, and **Window Size** for the window itself), **Updates**, **Open Log Folder**, **Audio/MIDI Settings…** in the app, and a **Developer** submenu. It works with the keyboard and looks the same in every DAW.
- **The GLOBAL panel's note map names every target** (Machinedrum Editor): tracks, patterns A01 to H16, START and STOP. **Map a note** sends any note to any pattern, START or STOP. Maps from older backups now show as they are instead of being cut short.
