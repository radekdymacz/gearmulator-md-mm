# Machinedrum Editor + Monomachine Editor 0.3.2

Fixes and polish on top of [0.3.1](https://github.com/radekdymacz/gearmulator-md-mm/blob/main/doc/release/v0.3.1.md): the Windows editor now opens, a new name, step selection on the Machinedrum, and rendering fixes for older Macs.

Screenshots, features and FAQ: **https://mdmm.dev**
User guide: **https://mdmm.dev/guide/**

## What's new

### Names
- The editors are now **Machinedrum Editor** and **Monomachine Editor**, by **Future Native Audio**, in your DAW's plug-in list, in Finder and in the window titles.
- The installers remove the old Gearmulator MD and Gearmulator MM bundles they put in place, so a DAW does not list the editor twice. Your ROMs, settings and old DAW projects are untouched: projects still load.

### Windows and Linux
- The Windows editor now works (WebView2): the window is no longer empty. Windows is still not tested in a real DAW.
- A Linux x64 build is available (not tested).

### Machinedrum
- Select steps with Option-click, Option-drag or the ruler, then copy, cut, paste, duplicate and delete them (Cmd-C, Cmd-X, Cmd-V, Cmd-D, Delete). Slide moved to Option-Shift-click.
- The LCD's values follow a drag.
- The first start loads the ROM once, not twice.

### Window and display
- Page Zoom in the right-click menu, and Cmd -, Cmd +, Cmd 0. The page always fits its window, and the plug-in window fits the screen (no more oversized window in Ableton Live).
- The MIX faders keep a sensible size at every window size.
- Older macOS (12 and later): the rendering fixes for the older Safari, and a visible play head on the white skin.
- The right-click menu no longer has a dead Settings entry. The standalone app has "Audio/MIDI Settings...".

### Standalone
- A Record menu writes the window and its sound to an .mp4 (macOS 15 and later).

### Requirements
- macOS 12 or later (Intel and Apple silicon). The installer now checks this.
- CPU use is unchanged: about half a core per instance.

## Known limits
- Not notarised by Apple: on macOS 15 and later use Open Anyway in System Settings > Privacy & Security.
- High CPU in some hosts is not fixed yet.

Report a problem: **https://mdmm.dev/contact/**
