# Machinedrum Editor + Monomachine Editor 0.3.3

A fix release on top of [0.3.2](https://github.com/radekdymacz/gearmulator-md-mm/blob/main/doc/release/v0.3.2.md), with the first steps towards updating from inside the app.

Screenshots, features and FAQ: **https://mdmm.dev** · User guide: **https://mdmm.dev/guide/**

## Fixes
- **No more swing while editing parameter locks (Machinedrum).** Each lock edit sends the whole pattern to the machine; it used to arrive all at once and stall the machine's sequencer for up to 17 ms. It now goes in at a steady pace, and the editor checks the machine once after you stop editing. Timing while dragging a lock lane: worst error 16.9 ms before, under 4 ms now.
- **The Sampler fills on the very first start** of a new install (it stayed empty until the editor was restarted).
- A SysEx message that a host delivers in pieces now reaches the machine once, not twice (from upstream Gearmulator).

## New
- **Update check:** once a day the editor asks https://mdmm.dev/latest.json whether a newer version exists and shows a small notice. Nothing else is sent; turn it off in the new **Updates** menu. Installing from inside the app comes in a later release.

## Testing
- Every release is now checked on the exact files we ship before they are published: the apps and plug-ins start and show their editor on macOS, Windows and Linux, Apple's AU validation, and pluginval (strictness 5) on every VST3 and AU.

## Platforms
- macOS 12 or later (Intel and Apple silicon), not signed by Apple yet: the first install needs **Open Anyway**.
- Windows x64 and Linux x64: not tested by a person yet. Feedback welcome: https://mdmm.dev/contact/
